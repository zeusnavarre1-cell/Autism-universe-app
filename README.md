# El Mundo de Juanito - Autism Universe 🌟

Una aplicación móvil **completamente desarrollada** para ayudar a personas con **TEA (Trastorno del Espectro Autista)**, autismo, TDAH y dificultades sensoriales.

## 🎯 Objetivo

Crear un entorno **seguro, relajante, educativo y divertido** con:
- ✅ Actividades interactivas
- ✅ Comunicación visual con pictogramas
- ✅ Rutinas organizadas y visuales
- ✅ Herramientas emocionales
- ✅ Sistema de recompensas
- ✅ Zona de relajación sensorial

## 🚀 Instalación Rápida

### Requisitos Previos
- Flutter 3.0+
- Dart 3.0+
- Android Studio / Xcode
- Cuenta Firebase

### Setup
```bash
# Clonar repositorio
git clone https://github.com/zeusnavarre1-cell/autism-universe-app.git
cd autism-universe-app

# Instalar dependencias
flutter pub get

# Configurar Firebase
flutterfire configure

# Ejecutar en desarrollo
flutter run

# Build Android
flutter build apk --release

# Build iOS
flutter build ios --release
```
